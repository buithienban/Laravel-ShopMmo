# ShopMmo - Hệ Thống Bán Hàng MMO

ShopMmo là một nền tảng thương mại điện tử chuyên biệt dành cho cộng đồng kiếm tiền online (MMO). Hệ thống cho phép mua bán tài khoản, sản phẩm số, thẻ game, dịch vụ thuê Apple ID và nhiều tiện ích khác.

---

## Giới Thiệu

- **Tên dự án:** ShopMmo
- **Phát triển bởi:** Bùi Thiện Bản
- **Quyền sở hữu:** Fastvnteam
- **Ngôn ngữ:** PHP (Laravel Framework)
- **Cơ sở dữ liệu:** MySQL
- **Front-end:** Blade Template, Bootstrap
- **Yêu cầu:** PHP 8+, Composer, Node.js (nếu dùng build front-end)

---

## Tính Năng Chính

- Quản lý sản phẩm (tài khoản, key bản quyền, dịch vụ)
- Thanh toán tự động qua ngân hàng (ACB, Vietcombank, MBBank, BIDV, Vietinbank...)
- Giao dịch tự động hoá bằng websocket
- Quản lý đơn hàng, người dùng, báo cáo vi phạm
- Booking thuê Apple ID, bảo hành tự động
- Quản trị CMS: bài viết, danh mục, thẻ nạp, ...
- Dashboard thống kê doanh thu, hoạt động người dùng
